Privacy Policy for Frequent Results

Last updated: July 2026

Frequent Results ("the App") does not collect, transmit, store, or share any personal data, location data, or device identifiers.

  • Data Storage: All saved number combinations and user preferences are stored strictly on your local device.
  • Third-Party Services: The App fetches public draw data via free public API endpoints. No user identification data is sent during API requests.
  • Contact: For privacy inquiries, contact support at mop_pit.7q@icloud.com.
